⚙️ CodeLog Settings

One fine-grained token, one repo. CodeLog never sees anything else — the token stays in your browser's local extension storage.
Create it with access to ONLY your solutions repo → permission: Contents: Read and write. Steps below.
More platforms (GFG, AtCoder…) are a contribution away — each one is a single adapter file.
How to create the fine-grained token (once, ~2 min):
1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
2. Repository access → Only select repositories → pick your solutions repo (e.g. dsa)
3. Permissions → Repository permissions → Contents → Read and write. Nothing else.
4. Generate, copy the github_pat_… value, paste it above. Done — this token physically cannot touch any other repo.
